# formsandlettersss

Interactive generative artwork built from a finite alphabet of hand-made forms.

## Files

- `index.html` — page shell
- `art.js` — generative artwork and interactions
- `alphabet.json` — source silhouettes
- `favicon.svg` — site icon
- `worker.js` — archive API worker
- `wrangler.toml` — Cloudflare Worker configuration

The R2 bucket name in `wrangler.toml` can be changed to match the deployment environment.
